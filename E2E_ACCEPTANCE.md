# E2E-приёмка (Playwright, синтетика)

Вспомогательная регрессия. Критерий MVP — проверка на реальных данных (PROCESSING_ACCEPTANCE.md).

## Результат последнего полного прогона

- Всего сценариев: 14. Проходят: 10. Падают: 4.

## Обязательная группа (1, 2, 5, 6)

Стабильно проходит три прогона подряд (6 из 6 в каждом):

- s01 — запуск, экран, суммы на 1440 и 800 px
- s02 — PNG, поля и оригинал
- s05 — исправление, подтверждение, перезапуск без потери данных
- s06 — повторная загрузка того же файла: без второго расхода и без вызова LLM

## Падающие сценарии (не в обязательной группе)

| Сценарий | Причина | Тип |
|---|---|---|
| s03 текстовый и сканированный PDF | подпись предпросмотра PDF не найдена в интерфейсе | требует проверки предпросмотра PDF |
| s04 неполные данные | тест ждёт отсутствия текста «ИНН», интерфейс выводит предупреждение о ненайденном ИНН | ожидание теста |
| s08 комиссия отдельной строкой | таймаут 180 с на «Обработка завершена» | нестабильность обработки в тесте |
| s10 ошибка AI и повтор | тест ждёт `LLM_UNCERTAIN` для документа, который распознаётся | устаревшее ожидание |

## Исправления тестов в этом этапе

- Ожидание состояния вкладки (повтор клика при сбросе Streamlit).
- Период: закрытие календаря кликом по заголовку вместо Escape (Escape откатывал выбранный день).
- Поиск вкладки «Документы» и подписи через видимую панель.
